# Support

mikrokhoros is pre-release software maintained on a best-effort basis.

- Use the repository's issue templates for reproducible bugs and focused feature
  proposals.
- Use repository discussions, when enabled, for setup questions and open-ended
  product conversation.
- Include your operating system, `swift --version`, the mikrokhoros commit, the
  command you ran, the output of `khoros doctor`, and a redacted error message.
- Never post API keys, `.env` files, credential values, private prompts, or a real
  workspace containing sensitive messages.

Security vulnerabilities must be reported privately according to
[SECURITY.md](SECURITY.md).
